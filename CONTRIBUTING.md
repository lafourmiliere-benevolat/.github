# Contributing

Thanks for helping La Fourmilière. These guidelines apply to every repository
in the organization; a repository's own `CONTRIBUTING.md` takes precedence.

## Questions

For questions about the association or volunteering, email
[bienvenue@lafourmiliere-benevolat.fr](mailto:bienvenue@lafourmiliere-benevolat.fr).
Issues are for bugs and changes to the code.

## Issues

Search existing issues first. For a bug, include steps to reproduce, what you
expected, and what happened.

## Pull requests

- Open an issue before large changes, so we can agree on the approach.
- Keep each pull request to one change.
- Add or update tests when behavior changes.
- Explain what changed and how you tested it.

## Security

Never report vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).

## Code of Conduct

By participating, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
