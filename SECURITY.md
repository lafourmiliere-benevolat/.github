# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions,
or pull requests.

Email [tech@lafourmiliere-benevolat.fr](mailto:tech@lafourmiliere-benevolat.fr)
with "Security" in the subject. On a public repository, you can instead use
**Security** → **Report a vulnerability**.

Include the affected repository, a description of the issue, and steps to
reproduce. We will acknowledge your report and keep you informed as we fix it.
