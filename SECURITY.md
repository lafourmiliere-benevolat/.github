# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions,
or pull requests.

Report them privately through the repository's **Security** tab →
**Report a vulnerability**. If that is unavailable, email
[tech@lafourmiliere-benevolat.fr](mailto:tech@lafourmiliere-benevolat.fr)
with "Security" in the subject.

Include the affected repository, a description of the issue, and steps to
reproduce. We will acknowledge your report and keep you informed as we fix it.
